# 🍽️ Food Portal — Class 12 Computer Science Project

## 📌 Project Description

Food Portal is a Python-based food ordering application developed as part of my Class 12 Computer Science project. It uses MySQL for database connectivity and demonstrates programming concepts through a menu-driven application.

## 🎯 Objectives

- Develop a simple food ordering application.
- Practise Python programming and functions.
- Understand database connectivity using MySQL.
- Organise program data and handle user input.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Database:** MySQL
- **Database Connector:** MySQL Connector/Python

## ✨ Features

- Food ordering interface
- Menu and order management
- Database connectivity with MySQL
- Menu-driven program flow

## 💻 Requirements

- Python 3
- MySQL Server
- MySQL Connector/Python
- A code editor such as VS Code or IDLE

## ⚙️ Setup and Execution

1. Install Python and MySQL Server.

2. Install the MySQL connector:

   ```bash
   pip install mysql-connector-python
   ```

3. Create the `food_portal` database in MySQL if it does not already exist.

4. Update the MySQL username, password, and database settings in the Python file.

5. Run the Python program:

   ```bash
   python "Class 12th CS PROJECT FOOD PORTAL (1).py"
   ```

   Use the actual filename shown in your repository if it differs.
